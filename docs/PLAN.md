# План ядра Atari 2600 VCS для Karabas Go / Mini / Mini G

Цель: Atari 2600 VCS (6507, TIA, RIOT 6532, картриджи с переключением банков) на платах Karabas (XC6SLX25, ISE 14.7). Основа — 2600-часть ядра **k7800** ([Atari7800_MiSTer](https://github.com/MiSTer-devel/Atari7800_MiSTer), Jamie Blanks, MIT) через `sv2v`; **запасной вариант** — A2601 Retromaster в редакции [A2600Nano](https://github.com/MiSTle-Dev/A2600Nano) (VHDL, GPL v3). Из A2600Nano берём обвязку в любом случае. Файлы идут через прошивку (OSD, `FL`, `F`): загрузчика и soft-CPU в ядре нет. Репозиторий `andykarpov/karabas-go-core-atari2600`.

### Мапперы

- A2600Nano: F8 F6 FE E0 3F F4 P2 (DPC, Pitfall II) FA CV 2K UA E7 F0 32 + SuperChip. AR / 3E / SB / WD / EF / DPC+ / CDF определяются `detect2600`, но в `A2601top.vhd` у них пустые ветки.
- k7800: всё перечисленное плюс AR (Supercharger), 3E, SB, WD, EF, FA2, JANE, 0840, FC, DF, MC и др. **ARM-мапперы (DPC+, CDF, ACE — ARM7TDMI на ~70 МГц) не делаем**: как MiSTer, показываем «Out of Order». Define `NO_ARM_MAPPER` убирает только `arm_mapper_subsystem`; `mapper_dpcplus` / `mapper_cdf` / таблицы остаются — вырезать в Ф0.

### Ф0: вся машина (2026-11-11, `make atari2600-xst`)

| Часть | LUT | FF | RAMB16 | Fmax |
|---|---|---|---|---|
| `atari2600_top` (sally + TIA + M6532 + `cart2600_kg` + `detect2600`, ПЗУ / RAM картриджа снаружи) | 6325 (42 %) | 2060 | 3 | 62 МГц |

Что понадобилось для XST:
- `cart2600` → своя копия `src/rtl/karabas/cart2600_kg.sv` без ARM: DPC+ / CDF / BUS (все ревизии) и ELF дают экран «Out of Order»; нет портов DDR3 / ARM / таблиц / загрузки; у FA2 пока нет сохранения во flash (nvram читается FF). Мапперная часть и мультиплексор — текст upstream. Константы `BANK*` XST понимает, если `detect2600.sv` (там `typedef enum`) идёт в тот же запуск sv2v.
- `mos6502_ctl.sv`: ранний `return` в функции `op_a` sv2v превращает в `_sv2v_jump`, XST после этого считает `op_a` неприсвоенной и подключает к нулю (АЛУ без операций!). Переписано на `if / else` (`// karabas:`). Проверка: в `.syr` нет `Xst:653` и `_sv2v_jump` в `rtl/sv2v/`.
- `banks2600.sv`: `header_array.sum()` (Supercharger) sv2v не переводит — явная сумма; пути `$readmemh` ПЗУ AR / «Out of Order» — от `src/`.
- Выкинутые XST регистры (Xst:1710): `rreg` TIA, NMI / IRQ / SO / halt CPU (входы привязаны), старшие биты счётчиков — норма.

Верх машины `src/rtl/karabas/atari2600_top.v`: фазы CPU только от TIA (`phi0_gen` / `phi1_gen`, без `cpu_phase_controller` и MARIA); декодер 2600 (A12 — картридж, A7 — TIA / RIOT); шина с удержанием заряда и масками `oe` как в `top.sv`; сброс CPU / RIOT / картриджа держится 5 фаз после выхода TIA из сброса (делитель TIA в сбросе стоит, а sally нужны фазы, чтобы увидеть сброс); пауза — снять `tia_ce`; звук — таблица k7800. Порты: поток загрузки (для `detect2600`), `mapper_force`, ПЗУ (`rom_a` / `rom_read` / `rom_do`) и RAM картриджа (до 256 КБ) — наружу, в SRAM платы (Ф2). Симуляции ещё не было: это Ф1.

### Ф1: симуляция (2026-11-11, `src/sim/`)

Verilator 5.020 собирает и гоняет машину как есть: петли `TIA.sv` ему не мешают (`-Wno-UNOPTFLAT`). Около 1 кадра в секунду.

- `sim_a2600.cpp` + `run_sim.sh`: `atari2600_top` на моделях ПЗУ / RAM картриджа на C++, картридж подаётся потоком загрузки (`detect2600`) под сбросом, кадры в PPM (палитра NWARM k7800), CE с шагом `--div` и дрожанием `--jitter` (как дробный CE платы), сброс посреди прогона `--reset-at`, проверки `--expect-*`; `DEBUG=1` — сборка с открытыми внутренними сигналами для `--trace-riot`.
- `run_checks.sh` (20 с): свои тестовые картриджи `roms/mkrom.py` — полосы (CPU + TIA + ADC + PF), таймер RIOT, F8.
- `run_gamebub.sh` (~5 мин): тесты мапперов [gamebub-2600](https://github.com/Wenwald/gamebub-2600) (MIT, тоже порт 2600-режима k7800; исходники скачиваются на закреплённом коммите, собираются `dasm`): **35 из 35** — 2K, CV, 4K+SC, F8 / F6 / F4 (+SC), FA, FA2, E0, 3F, 3E, FE, E7, F0, UA, WD, EF (+SC), SB 128 / 256, 0840, FC, DF / BF (+SC), P2 (DPC), CTY, MC 2K / 4K / 8K, 32-in-1 (переход к следующей игре по сбросу). FE, CTY, MC и 32-in-1 автоопределение по образу не узнаёт (Stella — только по базе / имени): маппер выбирается вручную (OSD, Ф3). Не проверены: AR (Supercharger), JANE.
- `stella_snap.sh`: эталонный кадр Stella 6.7 (Xvfb + `xdotool`, свой `basedir`). Homebrew со свободной лицензией (только локально, `~/Downloads/karabas-sd-atari2600`): Legendary Spear (2K, MIT), Refhraktor (F6, MIT), Kaz's Knickers (F6, GPL3) — 262 строки, кадры совпадают со Stella (кроме палитры).
- Сравнение с A2601 отпало: его VHDL Verilator не берёт, а Stella — лучший эталон.

Найдено и исправлено (`// karabas:`):
- **M6532**: запись в таймер в такт, когда счётчик проходит 0, проигрывала переполнению: `rollover` оставался 1, таймер считал каждый такт до чтения INTIM (TIM64T = 43 считал как 40). Теперь запись главнее (как в 6532 и Stella). Ошибка upstream.
- 32-in-1: счётчик игр сбрасывается при загрузке образа (как gamebub-2600), первая игра — 0.

В `TIA` XST выкинул 214 бит `rreg` — неиспользуемые биты регистров чтения (коллизии), это норма. Места на LX25 хватает с большим запасом в обоих вариантах; вопрос не в объёме, а в том, переживёт ли `TIA.sv` (намеренные комбинационные петли и асинхронщина) XST / PAR / Verilator.

A2601top: единственная конструкция VHDL-2008 — `process(all)` в `A2601top.vhd` (строка 322), заменяется списком чувствительности.

## Решения

Пользователь (2026-11-11): **вариант B с откатом на A** — основа k7800, при неудаче в Ф0 / Ф1 переход на A2601 (A2600Nano). Репозиторий создал пользователь.

Предложение (ждёт подтверждения там, где помечено «?»):

1. **Основа** — rtl k7800 как есть (`src/rtl/k7800/`, без правок, коммит импорта) и его `sv2v` в `src/rtl/sv2v/` (как atarist / archie); правки для XST в исходниках с пометкой `// karabas:`. A2601 лежит рядом (`src/rtl/a2601/`) как запасной вариант и эталон для сравнения в симуляции.
2. **Свой верх машины** `atari2600_top` (Verilog-2001, `src/rtl/karabas/`): mos6502 + TIA + M6532 + cart2600 + detect2600; по образцу 2600-ветки `top.sv` k7800, без MARIA / POKEY / BIOS 7800 (режим 7800 — возможное продолжение, вариант C).
3. **Частоты.** k7800: `clk_sys` = 14,318 МГц NTSC (4 × поднесущая) / 14,188 PAL, TIA получает CE 2 × цветовой такт. У нас — одна частота платы (кратная, например 57,27 МГц = 4 × 14,318, или ближайшая доступная PLL) и дробный CE, как `archie_ce.v`: видео уходит в кадровый буфер, дрожание CE на такт ему не мешает. Точная высота звука — проверить.
4. **Картридж в SRAM** (4 МБ на всех платах) через `FL` (`/atari2600/*.a26 .bin`), до 512 КБ ROM (3E) + RAM картриджа (SuperChip, FA, E7, 3E — 256 КБ) там же или в BRAM для маленьких. Автоопределение маппера — `detect2600` при загрузке (поток байтов FL); ручной выбор маппера в OSD?
5. **Видео: кадровый буфер в BRAM** — 160 × до 256 строк × 7 бит (индекс палитры NTSC / PAL / SECAM) ≈ 18–20 RAMB16; вывод в один стандартный режим (720p60 или 800 × 600 — ?), картинка 160 → ×4 / ×5 по горизонтали, строки ×2 / ×3. Неровное число строк у игр (VSYNC в разных местах) ловит `video_stabilize` из k7800 / A2600Nano. Режим 50 Гц для PAL-игр — ?
6. **Управление.** Джойстики USB через прошивку (`kg_mcu` HID / MD2), две кнопки (Fire 2 для доработанных игр). Пэдлы — мышью (`paddles.sv` k7800; аналоговые стики — после шага 6 HID-плана прошивки). Консольные переключатели — Menu + F-клавиши (Select, Reset/Start, Color/B&W, Difficulty L/R, Pause); **F12 = сброс** (правило ядер). Клавиатурные контроллеры / Kid Vid / AtariVox — позже или никогда.
7. **Свой верх платы**, общий код через modules (`kg_mcu`, OSD, HDMI, PCM5102), Makefile как у atarist / archie. Первым — Mini G, затем Go и Mini. Mini G2: T3 = 0 (SDRAM ~CS).

Пользователь (2026-11-11, перед Ф2): вывод **1280 × 720 @ 60** (пробуем на мониторе; не прошёл тайминг — см. ниже, решение: **1024 × 768 @ 60**); имя `atari2600` (`atari2600.kg`, `/atari2600`), `order` 21; картридж по умолчанию — homebrew **Legendary Spear** (DChristianson, 2K, MIT: `src/roms/legendary_spear.bin` + `LICENSE-legendary-spear`, в `.kg` как ROM, грузится прошивкой при старте ядра).

### Ф2: устройство (Mini G)

- 720p (74,25 МГц, сериализатор 371 МГц на ODDR2) не прошёл тайминг на -2: сдвиговые регистры сериализатора далеко от OLOGIC пинов (−0,8 нс), island encoder zhdmi на 74 МГц (−3…−6 нс, и с буфером пакетов на триггерах modules #26). Пользователь (2026-11-11): «давай 1024» — **1024 × 768 @ 60** (VESA 65 МГц), как у macplus.
- Частоты (`a2600_clocks.v`): один PLL от CLK_50MHZ, VCO 650 МГц: /2 = 325 МГц и 325 МГц / 180° — сериализатор HDMI; /10 = `clk_pix` **65 МГц**; /20 = `clk_sys` **32,5 МГц** (машина, MCU, SRAM, звук); /81 = 8,02 МГц (FT_CLK_OUT). `clk_sys` и `clk_pix` с одного PLL, пути между ними синхронные. В ucf `AREA_GROUP AG_TMDS` держит регистры сериализаторов у пинов TMDS (без него 2 пути shift_r → ODDR2 −0,53 нс).
- CE TIA (`a2600_ce.v`): NTSC 63 / 286 от `clk_sys` — ровно 7,159091 МГц; PAL 12446 / 57021 (+0,001 ppm).
- Картридж (`a2600_sram.v`): ПЗУ с 0 (до 512 КБ), RAM картриджа с 1 МБ; чтение — 3 такта (92 нс) против цикла 6507 838 нс, запись — 3 такта, пока `cartram_wr` поднят, повторяется (последняя — с итоговыми данными).
- Поток загрузки (`a2600_core.v`): ROM `.kg` (ROMLOADER) или FL «Cartridge» (слот 0) → SRAM и `detect2600`, машина в сбросе; до первого картриджа — сброс.
- Кадровый буфер (`a2600_fb.v`): 160 × 240 × 8 бит (5 банков 8K × 8 = 20 RAMB16), окно: x с 50-го цветового такта после HSYNC, y с 16-й строки после VSYNC (NTSC-строки 40…231 по центру); вывод 1344 × 806 (синхро отрицательные, VESA), ×6 / ×3 = 960 × 720 по центру 1024 × 768 (поля 32 / 24), палитра NWARM; один буфер (возможен медленный «шов» 59,92 / 60,004 Гц).
- OSD: `kg_osd_overlay` 512 × 416 (шаг 2 / 2), смещения 276 / 105 (как macplus); звук HDMI 48 кГц: +48 по модулю 65000.
- Управление (`a2600_hid.v`): пады (левый = P0, правый = P1), клавиатура — стрелки + Space / Left Ctrl (P0), F1 Select, F2 Game Reset, у пада Start = Game Reset, Mode / X = Select; F12 — сброс машины. OSD: Cartridge, Reset, TV Type (Color / B&W), Left / Right Difficulty (B / A).
- Симуляция платы без обвязки: `src/sim/run_board.sh` (`a2600_core` + модель асинхронной SRAM, клоки 2 : 1, загрузка как ROMLOADER или `--file`, кадр 1024 × 768): Legendary Spear, F8SC / FA / E7 / 3E (RAM картриджа через SRAM) — верно.
- Плата (Mini G, 2026-11-11, сборка 26111101): 1024 × 768 принят, Legendary Spear с `.kg` при старте, клавиатура (стрелки, Space, F2, F12 — сброс), звук HDMI, OSD по центру; FL: gamebub F8SC / E7 / 3E — PASS, Refhraktor (F6) грузится. TV Type B&W на Legendary Spear не видно (игра не читает переключатель; проверить на другой игре).

### Ф3: мапперы и опции

- OSD **Mapper** (индекс 5): Auto или принудительный — FE, CTY, MC 2K / 4K / 8K, 32-in-1 (их автоопределение не узнаёт), E0, E7, 3E, 3F, UA, 0840, SB, WD, F0 (16 вариантов — предел пункта). Код = номер `BANK*` detect2600 (`a2600_core.v`, `mapper_code`), смена — сброс машины.
- OSD **Region** (6): Auto (счёт строк TIA, `is_pal`), NTSC, PAL, SECAM. Регион меняет CE TIA (NTSC 63 / 286, PAL 12446 / 57021; SECAM — частота PAL), палитру (NWARM / PWARM k7800, SECAM — 8 цветов по яркости, как Stella) и окно кадрового буфера (Y0 16 / 42: PAL-строки 48…276). Вывод остаётся 1024 × 768 @ 60 (50-герцовые игры показываются с повтором кадров).
- OSD **Controller** (7): Joystick / Paddles (левый порт). Пэдлы (`a2600_paddles.v`): A — мышь по X и влево / вправо P0 (стрелки, левый пад), огонь — левая кнопка мыши / огонь P0; B — влево / вправо P1, огонь — правая кнопка / огонь P1. Заряд — `paddle_timer` k7800 (через sv2v): мерит окно, в котором игра читает INPTx, и раскладывает 256 положений по нему. В режиме джойстика B / C пада (и Left Alt) — Fire 2 / 3 на контактах 9 / 5 (Booster Grip); огонь — только A (раньше A или B).
- Настройки OSD хранит прошивка в `/config/atari2600.ini` (`.eep` не нужен).
- Проверено в `run_board.sh`: FE, CTY с принудительным маппером — PASS (MC / 32-in-1 — тесты из нескольких игр, нужны сбросы; проверены в Ф1); PAL / SECAM; пэдл — свой тест `roms/mkrom.py paddle` (заряд вверху / посередине / нет при мыши вправо / 0 / влево).
- **Плата Mini G, сборка 26111102 (2026-11-11) — OK:** пункты OSD видны; gamebub FE / CTY с принудительным маппером — PASS; Region PAL / SECAM меняют палитру, картинка стабильна; пэдл (тест `paddle`): мышь и стрелки двигают границу заряда во всём диапазоне; Kaz's Knickers, Refhraktor, Legendary Spear в режиме джойстика работают. B&W: ни одна из трёх игр переключатель не читает (проводка SWCHB D3 проверена по коду). Fire 2 / 3 на плате не проверены (нет игры). 50 Гц для PAL — не делали, открыто.

## Архитектура

```
 atari2600_top ├── mos6502 (6507) ── шина 13 бит ──┬── TIA (видео, звук, входы)
 (karabas)     │                                   ├── M6532 RIOT (RAM 128 Б, порты, таймер)
               │                                   └── cart2600 (мапперы) ── SRAM: ROM / RAM картриджа ← FL + detect2600
               ├── TIA col/lum ── video_stabilize ── кадровый буфер BRAM 160×256×7 ── палитра ── вывод ── OSD ── HDMI / VGA
               ├── TIA aud0/aud1 ─────────────────────────────────────────────────── HDMI / PCM5102
               └── порты RIOT / входы TIA ── kg_mcu HID (джойстики, мышь → пэдлы, клавиши → переключатели)
```

## Фазы

Ветка и один PR на фазу, слияние в конце фазы.

- **Ф0. Импорт и fit (ветка `f0-import`) — сделано 2026-11-11**, итог выше («Ф0: вся машина»). План был: rtl k7800 (2600-часть) и A2601 без правок; `src/tools/sv2v.sh` → `src/rtl/sv2v/`; правки XST: `cart2600` (константы перечислений, вырезать DPC+ / CDF / ARM), `M6532` с `cache_ram.v`; верх машины `atari2600_top`; `make atari2600-xst` — вся машина. Критерий: собирается, нет защёлок / петель, которые ломают PAR, Fmax ≥ рабочей частоты. Иначе — откат на A2601 (`make a2601-xst` уже работает).
- **Ф1. Симуляция (ветка `f1-sim`) — сделано 2026-11-11**, итог выше («Ф1: симуляция»). План был: Verilator: `atari2600_top` + модель SRAM картриджа, кадры PPM. Тесты: свободные тестовые ROM (TIA / HMOVE, если найдутся) и игры пользователя разных мапперов; сравнение кадров с A2601 и со Stella. Петли `TIA.sv` в Verilator — главный риск варианта B.
