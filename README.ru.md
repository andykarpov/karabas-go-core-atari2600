# Ядро Atari 2600 VCS для Karabas Go / Mini / Mini G

[English version](README.md)

Atari 2600 VCS (6507, TIA, RIOT 6532, картриджи с переключением банков) для плат семейства Karabas Go (Xilinx Spartan-6 XC6SLX25). Основа — 2600-часть k7800 ([Atari7800_MiSTer](https://github.com/MiSTer-devel/Atari7800_MiSTer), Jamie Blanks); A2601 Retromaster в редакции [A2600Nano](https://github.com/MiSTle-Dev/A2600Nano) — запасной вариант и источник обвязки.

Состояние: в работе (см. `docs/PLAN.md`). На плате пока ничего не запускается.

Игр в комплекте нет: образы картриджей — свои, на SD-карте в `/atari2600`.
